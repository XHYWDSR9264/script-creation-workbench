# 剧本创作总控台

这是独立于“短剧生产助手”和“爽文出海创作台”的短剧生产工作台。当前版本为 v0.4.0，项目、素材、正文版本、结构审计、朱雀同版证据和基础导出均可真实落库。

## 本地运行

在当前目录执行：

```powershell
python server.py
```

然后访问：

```text
http://127.0.0.1:8786
```

本地版写入本目录的 `workbench.sqlite3`。模型接口由用户在网页中配置，API Key只保存在当前浏览器会话，不写入数据库和日志。

## GitHub

本项目发布为独立公开仓库。仓库中不包含本地 SQLite 数据库、运行日志和任何密钥；这些内容只保留在本机工作目录或部署平台的秘密管理中。

## 在线预览

当前已部署到 Cloudflare Workers：

https://script-creation-workbench.xhywdsr9264.workers.dev

在线版使用独立的 Cloudflare D1 数据库；本地版仍使用本目录的 SQLite，二者数据互不混用。

## 当前数据能力

- 项目基本信息和生产路线
- 地区、呈现形式、总集数、提交范围和开头模板
- 剧情梗概、人物小传、世界观和卡点矩阵独立版本
- 正文不可覆盖版本、提交集数范围和SHA-256
- G0—G6 SOP闸门
- 项目活动日志
- 项目素材库：TXT/MD即时提取，DOCX/PDF保留原文件并绑定SHA-256
- Cloudflare R2原始素材存储（线上）与项目隔离文件存储（本地）
- OpenAI兼容的Responses API / Chat Completions模型调用与接口测试
- 正文结构审计报告，明确区分自动结构检查与人工内容终审
- 朱雀网页真实指标、报告截图和正文SHA-256绑定登记
- TXT合并稿与JSON项目快照导出

尚未完成：朱雀官方API自动调用、DOCX/PDF正式模板排版、完整人工内容评分和网站访问控制。在线地址目前属于公开预览环境，请勿上传未获授权或含敏感信息的素材。
